The JetBrains AI ecosystem is a set of AI solutions for professional software development that combines:

  • AI features in JetBrains IDEs – from AI-enhanced functionality for coding, version control, and database tasks to agentic workflows.
  • The JetBrains coding agent Junie.
  • Integrated third-party AI agents such as Claude, Codex, and Gemini, with additional agents available through the Agent Client Protocol (ACP).
  • The agentic development environment JetBrains Air.
  • Enterprise AI governance and execution through JetBrains Central.

JetBrains connects these tools and capabilities into one system, enabling teams to scale from lightweight AI assistance to fully agent-driven workflows with centralized governance and control.

JetBrains provides an open and controlled system for building software with AI.

Completely open platform – no vendor lock-in

Use JetBrains AI, connect your own providers through API keys (BYOK), run local models, or bring external agents via ACP-compatible integrations.

Designed to keep you in control

AI assists and automates development, but decisions, code quality, and ownership remain with developers.

Built into real development workflows

AI is integrated across JetBrains IDEs and tools, offering support for coding, testing, CI/CD, collaboration, and more.

Enterprise-ready by design

Control data, model usage, and deployment, and scale AI safely across teams with governance and visibility.

From tools to a unified system

JetBrains Central connects IDEs, agents, and workflows into a single system for software development.

JetBrains helps teams move from AI-assisted coding in IDEs to fully integrated, AI-powered development systems across tools and workflows, with no loss of control.

JetBrains products are designed as an open ecosystem for coding agents. Integrated options include Junie by JetBrains, OpenAI Codex, Claude Agent, and Gemini CLI, all of which can be accessed using JetBrains AI or your own provider API keys. You can also connect ACP-compatible external agents, including tools such as Cursor and GitHub Copilot, directly to your IDE using their own authentication methods.

The JetBrains AI ecosystem supports a wide range of models:

Third-party models via JetBrains AI

Take advantage of a curated set of cloud models from leading providers, including OpenAI, Google, Anthropic, and xAI.

JetBrains proprietary and fine-tuned models

The code completion and next edit suggestion IDE features rely on JetBrains models like Mellum, which is optimized specifically for coding tasks.

User-provided and local models with bring your own key

Connect models from outside of JetBrains AI with bring your own key (BYOK) or OAuth where supported, or connect local models via tools like Ollama or LM Studio.

It provides:

  • Control over data, models, and usage.
  • Flexible deployment: cloud, on-premises, or isolated environments.
  • Centralized management of AI usage across teams.
  • Compliance with security and governance requirements.

This allows organizations to safely adopt AI at scale.

JetBrains keeps developers and organizations in control:

  • You choose which models and agents are used.
  • You control where data is processed.
  • You define how AI is applied in workflows.
  • You maintain ownership of code and decisions.

AI assists with development, but does not replace developer control.

Your code and data remain entirely yours.

You control how data is processed and which models or providers are used across your development workflows. If you choose to share data with us, this data is used exclusively to improve JetBrains tools and train our own models, like Mellum, and it is never shared with third parties.

For enterprise environments, JetBrains also provides options for local models, isolated deployments, and centralized governance. In these setups, JetBrains never even accesses your data.
