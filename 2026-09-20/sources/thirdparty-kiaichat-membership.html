Kimi Membership Pricing and Plan Comparison

By KI AI Team · Editorial lead: Ibrahim ALI
Updated September 17, 2026. Website prices and linked usage rules were checked on this date; this is a documentation review.

Kimi Membership is the personal subscription for Kimi’s hosted workspace. It covers agent features and currently includes Kimi Code benefits, but it does not include credit for the separate Kimi API Open Platform.

The official website lists four paid plans: Moderato, Allegretto, Allegro and Vivace. The price table below was rechecked on September 17, 2026. Prices are website list prices in USD; the annual equivalent is a calculation, not a monthly payment option.

At a glance: Paid Kimi plans start at $19 monthly or $180 annually. The highest listed tier is $199 monthly or $1,908 annually. Annual billing reduces the effective monthly rate but requires a full-year commitment.

Is there a free Kimi plan?

Kimi offers free access, but the linked English price table compares paid subscriptions. The credit rules mention free-tier usage examples without establishing one guaranteed allowance for every task. Check the balance and restrictions shown in your account before depending on free access for a deadline.

How Kimi membership credits work

Kimi uses a credit system that meters work by resource or token consumption. In practical terms:

  • Simple and complex tasks do not necessarily cost the same number of credits.
  • The official task-equivalent figures are estimates, not guaranteed message counts.
  • Higher tiers provide larger pools and, on some features, more concurrent work.
  • Bonus or promotional credits can have their own expiry rules.
  • K2.6 conversations in Chat also consume membership credits under Kimi’s current published credit rules.

Before subscribing, open Settings → Subscription & Invoices → My Quota in Kimi and compare the displayed rules with your expected workload.

Kimi Code limits inside membership

Paid membership currently includes Kimi Code. CLI and supported IDE requests draw from the shared membership allowance. Check two separate displays: the membership balance and Code’s five-hour and weekly usage windows. A Code window resetting does not refill the monthly membership balance.

The membership credit rules describe a monthly refresh on your subscription anniversary for both monthly and annual billing. Unused subscription allowance expires. The Code documentation also describes a weekly quota, a rolling five-hour window and a block when the membership monthly total is reached. Its seven-day quota should not be read as a fresh monthly allowance.

The Help Center benefits page still announces a planned split between membership and Code benefits without establishing a launch date here. Recheck the package offered at checkout; this guide does not treat a future announcement as an already completed change.

Extra Usage: the pay-as-you-go fallback

Extra Usage is an optional prepaid wallet for usage beyond subscription allowances. Kimi’s membership Extra Usage guide describes a USD balance, a $10 minimum top-up and a monthly spending cap that is off by default. Subscription credit is used first; an enabled wallet can cover overflow when eligible limits are reached. You can disable wallet spending in the web settings.

Check the currency in your account: the Code benefits documentation instead describes an RMB balance and a ¥25 minimum. These are different published rules, not interchangeable currency conversions. We have not established which wallet presentation applies to every region or account. Confirm the displayed currency, top-up amount, rate and cap before enabling it.

The documentation says unused Extra Usage funds do not expire and can remain usable after a subscription lapses, while new top-ups require an active subscription. A wallet balance is separate from Open Platform API credit. This review did not make a top-up or measure live deductions.

Credit deductions that can continue in the background

Two entries on the official membership pricing page deserve special attention:

  • A deployed Kimi Claw cloud host can deduct about 0.6% of membership credits per day, settled at 4:00 PM according to Kimi. Save any files you need before deleting the cloud host to stop further deductions.
  • A website published through Agent can deduct about 0.08% of membership credits as a cloud-service charge while it remains online. Unpublishing stops that charge.

These are deductions from membership credits, not list-price increases. Still, they can reduce available usage even when you are not actively chatting.

Monthly or annual: which is better?

Annual billing is cheaper only if you expect to keep and use the plan. The saving compared with twelve monthly payments is:

  • Moderato annual billing saves $48 versus 12 monthly payments.
  • Allegretto saves $96.
  • Allegro saves $240.
  • Vivace saves $480.

Monthly billing is the safer evaluation option when you do not yet understand your credit consumption, need a feature still in beta, or expect the membership structure to change.

Which plan fits which user?

Moderato

Best starting point for an individual who regularly uses Agent or wants basic Kimi Code access. It has the same advertised speed priority as higher paid tiers but the smallest paid credit allocation.

Allegretto

Useful when Moderato’s credits are insufficient or you need Kimi Claw. It also qualifies for Kimi Code HighSpeed and K3’s 1M Code context; Agent concurrency remains two tasks. K3 Chat’s 1M entitlement starts at Allegro.

Allegro

Suited to heavier workloads needing four concurrent Agent tasks or K3 Chat context up to 1M tokens. The larger Project allowance can also matter for ongoing work. Measure monthly consumption before paying for the higher tier.

Vivace

The highest listed personal tier doubles Allegro’s published Agent task-equivalent estimate. Agent concurrency remains four, and the Project count and storage are the same as Allegro. Choose it when your usage exceeds the lower tier’s credits.

Before you subscribe

  1. Confirm that you are buying Membership, not Open Platform API credit.
  2. Check your account’s current plan table and quota wording.
  3. Verify the full annual charge and any tax before payment.
  4. Review auto-renewal and cancellation steps in the official help center.
  5. Start monthly if you have no usage history.
  6. If enabling Extra Usage, set a spending cap before depending on it.

Frequently asked questions

Is Kimi Membership unlimited?

No. Kimi describes plan-specific credit pools, concurrency and Kimi Code rate limits. “Unlimited” is not an accurate summary of the current official rules.

Does Kimi Membership include Kimi K3 API calls?

No. Personal membership and Open Platform API billing are separate. Kimi may make models available in its hosted products, but that does not create API balance.

Does unused membership credit roll over?

Do not assume that plan credits roll over. Kimi distinguishes time-limited subscription credits from Extra Usage balance, which it says does not expire. Check the live credit rules for the exact refresh and expiry behavior.

Can I cancel a Kimi subscription?

Kimi provides cancellation instructions in its Membership Help Center. Cancellation usually controls renewal; it should not be assumed to provide a refund for an already paid term.
